# 🩺 NetraSakhi — AI-Powered Rural Health Screening

> **An AI-powered health screening tool using Computer Vision and CNN-based classification to support preliminary disease and deficiency detection in rural healthcare centres.**

## 📌 Project

**NetraSakhi** combines image processing techniques such as **Canny Edge Detection, Hough Transform, and Contour Detection** with **Convolutional Neural Networks (CNN)** to analyse medical images and classify selected diseases and nutritional deficiencies.

The application also provides **vaccine and polio-drop date prediction** to support preventive healthcare management.

### 🔬 Conditions Covered

* 🩸 Anaemia
* 🦠 Chickenpox
* 🍄 Ringworm
* 💅 Leukonychia (Zinc Deficiency)

## 🎯 Objectives

* 🧠 Develop an AI-assisted image-based health screening system.
* 👁️ Apply Computer Vision for image preprocessing and feature extraction.
* 🔍 Classify diseases and deficiencies using CNN models.
* 💉 Predict upcoming vaccine and polio-drop dates.
* 🌾 Support accessible preliminary healthcare screening in rural areas.
* 📊 Enable structured digital health monitoring.

## ⚙️ Workflow

**Image Input** 📷 → **Preprocessing** 🖼️ → **Edge & Contour Analysis** 🔍 → **CNN Classification** 🧠 → **Disease/Deficiency Result** 📋 → **Vaccine Prediction** 💉

## 🌱 Impact

NetraSakhi aims to provide **AI-assisted preliminary screening and preventive healthcare support**, particularly for communities where access to timely healthcare resources may be limited.

> ⚠️ *The system is intended for preliminary screening support and does not replace professional medical diagnosis.*
